Dataset Description

This dataset contains daily average PM2.5 concentrations (µg/m³) recorded from 105 Air4Thai monitoring stations across Thailand throughout the year 2025. Each row represents one day, and each column (station code) contains the PM2.5 reading for that station on that date. Station codes follow the Air4Thai naming convention (e.g., 02T = Bangkok, 05T = Chiang Mai area). The data is sourced from the Pollution Control Department (PCD) of Thailand.

About Project

Project Overview

Understanding the science behind our PM2.5 prediction system

Background

Air pollution, particularly PM2.5 (fine particulate matter ≤ 2.5 micrometers), poses severe health risks including respiratory diseases, cardiovascular problems, and premature mortality. Thailand experiences significant PM2.5 pollution, especially during the burning season (January–April) in the northern regions. Traditional monitoring alone is insufficient — predictive capabilities are essential for proactive health protection. This project applies machine learning to forecast PM2.5 levels and provide actionable health risk alerts to citizens across Thailand.

Objectives

  • Develop a machine learning model to accurately predict daily PM2.5 concentrations across 105 monitoring stations in Thailand
  • Classify air quality into health risk categories (Good, Moderate, Unhealthy for Sensitive Groups, Unhealthy, Very Unhealthy, Hazardous)
  • Provide personalized health recommendations based on predicted PM2.5 levels
  • Create an interactive, user-friendly web interface for real-time air quality visualization and prediction
  • Analyze temporal and spatial patterns in PM2.5 data to identify high-risk periods and regions
